Bitdefender Design System

Role: Design System Designer | Timeline: 2020-2024 | Location: Bitdefender, Cluj-Napoca

Creating a scalable, company-wide design system to unify multiple products and accelerate development across Bitdefender's enterprise security platform.

OVERVIEW

The Challenge

Bitdefender was undergoing a platform redesign and had multiple products with UI inconsistencies. Four of us were chosen to create a design system that would serve the entire company.

  • Multiple products with different design patterns
  • Needed to work with many teams to understand component requirements
  • Required balancing consistency with specific product needs
  • Had to find a uniform solution with the Engineering team
MY ROLE

Responsibilities

  • One of four co-creators of the design system
  • Successfully completed the creation of components
  • Conducted workshops with colleagues and team members from different departments to explain new component functionalities
  • Collaborated with the Engineering team to facilitate component implementation
PROCESS

How We Built It

PHASE 1

Audit

Documented all existing products and their patterns

PHASE 2

Prioritization

Identified most frequently used components

PHASE 3

Design

Created components in Figma with close Engineering collaboration

PHASE 4

Documentation

Usage guidelines, when and how to use components

PHASE 5

Education

Workshops and presentations to teams, collected feedback

Component Development

We started with simple, frequently used components like toggles, inputs, filters, and dropdowns. This allowed us to build trust and prove the system's value before tackling more complex components.

COMPONENTS

Design System Library

Form Inputs

Comprehensive input components including dropdowns, phone inputs, date pickers, and radio buttons with full state coverage.

Navigation

Collapsible menus, user menus with theme controls, and accessibility features including font size adjustment.

Data Display

Light grids, tables with sorting and filtering, and side panels for detailed information views.

Complex Patterns

Wizards for multi-step processes, dialogs with various states, and smart views with search and organization.

RESULTS

Impact & Outcomes

Company-Wide

Adopted across all Bitdefender products

Faster

Accelerated design and development with Storybook

Consistent

Improved UI consistency across products

Technical Implementation

The design system was implemented as a web component library in Storybook, providing a clear and rapid implementation process for teams. This technical foundation enabled faster development cycles and ensured design-development alignment.

KEY LEARNINGS

What I Learned

Design Systems are 50% design and 50% people management

The technical work of building components is the easy part. The harder part was gaining colleagues' trust at the beginning when we were only presenting a few simple components, while we had the vision of the entire system in mind.

However, after implementing small components for a while, we moved on to high-impact ones like grids with filters and side panels, or wizards. That's when they started seeing the real benefits, which created momentum for wider adoption.

The Turning Point

The breakthrough came when we delivered complex, high-value components that solved real problems teams were facing. Seeing these components work seamlessly across different products demonstrated the system's true power and accelerated adoption across the organization.
